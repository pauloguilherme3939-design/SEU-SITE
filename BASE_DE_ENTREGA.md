## 🧭 Como usar este documento

**Antes da venda:**
- Mostre ao cliente em caso de dúvida específica ("isso está incluso?")
- Use como base para responder objeções ("por que esse valor?")

**Durante o briefing:**
- Marque cada item conforme cobre com o cliente
- Capture os "Limitações honestas" — evita surpresas

**Durante a entrega:**
- Use como checklist técnico — não esquece de configurar nada
- Cada item entregue = lista enviada ao cliente no fim

**Após a entrega:**
- Envia o checklist preenchido como comprovação de tudo entregue
- Cliente vê exatamente o que recebeu — reduz pedidos extras
